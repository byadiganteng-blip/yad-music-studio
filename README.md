# 🎵 YAD Music Studio

FL Studio clone untuk Android — drum machine, step sequencer, mixer.

## Fitur (Level 2)
- ✅ Step sequencer 16-step × 8 track
- ✅ Mixer 8 channel (volume per track)
- ✅ BPM control (60-180)
- ✅ Save/Load pattern (JSON)
- ✅ Demo pattern
- ✅ Sound preview saat tap
- ✅ Pure Kotlin + Android SDK
- ✅ Offline (tanpa internet)

## Cara Pakai
1. **Tap step** di sequencer → aktifkan/matikan
2. **Geser BPM** → ubah tempo
3. **Tap PLAY** → sequencer jalan
4. **Tap DEMO** → load pattern contoh
5. **Tap SAVE** → simpan pattern
6. **Tap LOAD** → muat pattern terakhir
